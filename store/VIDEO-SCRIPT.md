# Demo video script (about 30 seconds, no sound)

`store/demo-video.mp4` is a headless recording of the built Whozit panel with demo data, made by
`node scripts/shots.mjs`. Upload it to YouTube and paste the link in the store's video field.
Every frame shows the "Demo data" label. The company is made up (haldencycles.example).

| Time | On screen | Caption to add on YouTube (optional) |
| --- | --- | --- |
| 0:00 to 0:02 | Browser on haldencycles.example, Whozit open, the chip reads "Company website". | Open Whozit on any page. It knows what the page is. |
| 0:02 to 0:07 | "Who owns this website": listed price, "See price", the confirm box with the most it can charge, then the company card and "Charged $0.0019". | The company behind the domain, and what it cost. |
| 0:07 to 0:13 | Website traffic: visits per month, ranks, bounce rate, traffic sources. | Traffic estimate and where visitors come from. |
| 0:13 to 0:19 | Tech stack: 12 technologies as chips. | What the site runs on. |
| 0:19 to 0:30 | "More lookups" opens, Recent news runs, three headlines with sources and dates. Session meter at the bottom. | News, people and email lookups one click further. |

A longer cut for YouTube or looot.ai (60 to 90 s, recorded by hand in real Chrome with a real key):

1. Install from the store, pin the icon, open a real company site. Run "Who owns this website" and "Tech stack".
2. Open the company's team page. The panel puts "Find a work email" first. Type a name, run it, show the check.
3. Open a LinkedIn profile. The chip says "LinkedIn profile"; run the profile lookup, then the work email from it.
4. Open a news article. Run "Who owns this website" for the publisher and "Recent news".
5. Close on Settings: the key, the cap per call, the session cap.
