# Demo video script (21 seconds, no sound)

`store/demo-video.mp4` is a headless recording of the built panel with demo data, made by
`node scripts/shots.mjs`. Upload it to YouTube and paste the link in the store's video field.
Every frame shows the "Demo data" label. The company is made up (haldencycles.example).

| Time | On screen | Caption to add on YouTube (optional) |
| --- | --- | --- |
| 0:00 to 0:02 | Browser on haldencycles.example, looot panel open. Left side: "Company lookup for the site you are on". | Open looot on any website. |
| 0:02 to 0:05 | "Who owns this website": the listed price, then "See price" opens the confirm box with the most it can charge. | You see the price before anything runs. |
| 0:05 to 0:08 | Confirm and run. Company card: Halden Cycles, industry, 84 employees, 2014, Norway, Bergen, LinkedIn. Receipt: Charged $0.0019. | The company behind the domain, and what it cost. |
| 0:08 to 0:14 | Website traffic: confirm, then visits per month, global and country rank, bounce rate, traffic sources. | Traffic estimate and where visitors come from. |
| 0:14 to 0:21 | Tech stack: confirm, then 12 technologies as chips. Session meter at the bottom counts the spend. | Tech stack, with a session cap you set. |

A longer cut for YouTube or the looot site (60 to 90 s, recorded by hand in real Chrome with a real key):

1. Install from the store, pin the icon, open a real company site.
2. Paste the key in Settings. Show the cap per call and the session cap.
3. Run "Who owns this website", "Website traffic" and "Tech stack" on that site. Read the price line first each time.
4. Type a name in "Find a work email", run it, show the check result.
5. Switch tab to another site. The panel follows the tab. Close on the receipt and the session meter.
